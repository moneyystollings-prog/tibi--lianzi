# 字间个人练字网站实施计划

**Goal:** 在 D 盘交付可持续新增每日主题的完整个人网站，以及新周期第 1 天的双语练字材料、实际配图和可保存的写作区域。

**Architecture:** 每日 JSON 内容与页面模板分离，使用 Node.js 标准库构建可独立阅读的静态 HTML。小型本地 HTTP 服务仅向回环地址开放，将用户写作保存到 D 盘；不使用浏览器持久存储。首页、归档、每天固定链接由同一份内容生成。

**Tech Stack:** Node.js 24、HTML、CSS、原生 JavaScript，无第三方运行依赖。

## 已确认约束
- 用户已批准完整提示词并要求执行；新周期首次为第 1 天，旧周期不参与去重。
- 实际内容日期以当前用户时区为准：2026-10-27，Asia/Shanghai。
- 项目、输出、练习存储均在 D:/Codex/writehand。
- 用户单独允许内置生图临时写入 C 盘，生成后立即移至 D 盘；此例外不适用于其他项目文件。
- 当前交付本地完整网站；公开部署和定时任务留待明确要求。
- 工作名称「字间 / Between the Lines」；第 1 天主题「在寻常处，看见光 / Light in the Ordinary」。

## 文件职责
- `site/content/days/*.json`：逐句中英正文、出处、配图、练字字、题目、主题和状态。
- `site/public/assets/day-001/`：实际图片、生成提示词与图片来源记录。
- `site/src/template.mjs`：语义化 HTML 模板，统一导航与每日不同图文模块。
- `site/public/style.css`：纸白、墨色、暖金视觉，手机与打印排版。
- `site/public/app.js`：练字显示控制、筛选、写作输入、保存和导出。
- `site/scripts/build.mjs`：验证内容，生成首页、归档、每日页与阅读文本。
- `site/scripts/content.mjs`：内容读取、计数、排重、归档格式；不自动重置周期。
- `site/scripts/server.mjs`：本地静态服务，受限写作 API，D 盘保存和导出。
- `site/data/cycle.json`：新周期标识和已完成内容记录。
- `site/data/writing/`：用户练习；不纳入静态输出或版本控制。
- `site/tests/`：内容重复检测、路径约束、保存恢复和导出测试。
- `research/`：GitHub 调研、文学来源与话题核验。
