# 炼字填空调整

用户给出了明确参考：成对短句、句中单字留空，自由选择字词改变意境。本次按 brainstorming / writing-plans 的范围检查直接执行已授权修改。

设计：保留三组题，每组上下两句，每句一个单字输入框；集中展示中文，英文作为未填句式参考；实时呈现完整填句，不提供标准答案。保留原自由书写模块。使用独立 cloze1—cloze6 字段，避免旧 fill1—fill3 内容套入新题。

实施：更新每日 JSON 的 couplets；template.mjs 渲染题卡；app.js 更新预览和字段保存；writing-store.mjs 校验六个单字并导出成句；content.mjs 同步纯文本题。既有填词若有内容仍可在旧题记录中查看、保存与导出。

验证：检查旧记录兼容、六个空的保存恢复、完整句导出和超长输入拒绝，构建后在桌面与手机视口查看真实页面。所有新增文件在 D 盘。本次修改第 1 天的写作题，不新增第 2 天或清空去重历史。
